# 小白答疑

> 不急着给答案，先帮你把问题问对。

「我是小白，想学 AI，从哪开始？」「普通人怎么用 AI 赚钱？」「什么适合我？」「38 岁要失业了，有什么出路？」

这些问题你拿去问任何一个 AI，都会立刻拿到一份清单：学提示词、做自媒体、接单、学编程……再加一句「坚持就会有收获」。**清单没错，但对你没用**，因为它不知道你是谁、手上有什么、想要什么、卡在哪。

小白答疑反过来做：**它不先回答，先问你。** 一次只问一个问题，每个问题都告诉你为什么问、可以怎么答。问清楚之后，把你真正的问题拼成一句话给你确认，再给你**一件这周就能做完、做完看得见结果的事**。你做完回来，它接着陪你走下一步。

**支持**：Claude Code · Codex · Cursor · 豆包 · WorkBuddy，以及其他支持 Skills 的 AI 助手。

## 两种用法

| 你是谁 | 怎么叫它 | 你会拿到 |
|---|---|---|
| **有个问题想弄明白的人** | 直接说你的问题 | 它一轮轮问你，聊完给你：你真正的问题 + 这周的一步 |
| **做内容的博主**，粉丝老在评论区、私信问这类问题 | 把粉丝的原话贴进来 | 每一轮该回什么，写好放进剪贴板；每个粉丝一份聊天记录，下次接着聊 |

不用选模式，它听你说话自己会判断。判不准会问你一句。

## 第一次怎么用

装好之后，输入：

```
/xiaobai-qa 新手指南
```

它**不会先让你读一堆规则**，会这样带你走一遍：

1. 问你是哪种情况：自己有问题，还是替粉丝问。只有这一个必须回答
2. 让你用自己的话说一个真问题，一句话就行
3. 先告诉你：这句话直接问一个普通 AI，大概会拿到什么
4. 然后换一种方式，现场一个一个问你，你看着问题是怎么变清楚的
5. 收尾只让你记一件事，给你几个编号选项选下一步

大概十分钟。

### 不想走指南，直接问也行

下面这些原话都能直接用：

**自己问**
```
小白答疑：我是小白，想学 AI，不知道从哪开始
小白答疑：我在上班，想下班后用 AI 多赚点
小白答疑：38 岁的程序员，要失业了，有什么出路
小白答疑：我会写代码，想给公司做智能体，不知道怎么开始
```

**博主回粉丝**
```
/回粉丝 粉丝私信问：普通人怎么用 AI 赚钱
他回我了：3，暂时没工作
帮我回一下这些评论：（贴一串）
谁还没回
```

## 用和不用差在哪

拿一个真实的问题比一比：**「我是宝妈，在家带孩子，想用 AI 赚点钱」**

**直接问一个普通 AI**，你会拿到类似这样的东西：

> 1 做小红书分享育儿经验 2 接 AI 写作单 3 开网店 4 学 AI 绘画接单……选择适合自己的方向，坚持下去就会有收获！

谁都能用，谁用都没用。你还是不知道明天该干什么。

**用小白答疑**，它会先问你：

- 带孩子之外，一天能自己支配的时间有多少？（问这个，是因为一小时和四小时能做的事完全不一样）
- 带孩子以前做什么工作？身边的人常找你帮什么忙？（问这个，是因为你手上已有的东西，比新学一样快得多）
- 想要多少进账，多久之内？
- 试过什么，停在了哪？

聊完你拿到的是：

```
你一开始问的：「我是宝妈，想用 AI 赚点钱」
你真正要解决的：「我做过幼儿园老师，群里妈妈常找我问带娃的事，想每月先有一千块左右，卡在不知道这些经验能不能收钱」
这周的一步：把妈妈们问得多的三个问题，用 AI 整理成三页带娃小卡片发到群里，看有几个人私信你问更多
```

外加一句**下次你可以怎么问**，以后问谁都用得上。

## 它是怎么帮你把问题问清楚的

它心里有一张五格的卡，聊一轮补一格：

| 格 | 它想弄清的 |
|---|---|
| 处境 | 你在上班、开店、没工作，还是在读书 |
| 底子 | 你手上已经有什么：会的、做过的、认识的人、每周的时间 |
| 想要 | 具体想要什么结果，多久之内 |
| 卡点 | 试过什么，停在哪一步 |
| 约束 | 不想做的、做不了的，手上的钱能撑多久 |

前四格有了，它才会给建议。这也是你以后问任何人问题时，值得先说清楚的五样东西。

每一轮你会看到：

- **只有一个问题**，后面跟着「问这个，是因为……」和「比如可以这样答……」
- 选择题永远有「都不是，我自己说」
- 一行进度：「已经清楚：处境、底子。还差：想要、卡点。」

## 怎么装

先弄清一个词：**技能**就是一个文件夹，里面是写给 AI 看的说明。把这个文件夹放到 AI 助手认得的地方，它就学会了。下面按你用的工具选一种。

### 用豆包或 WorkBuddy（不用碰命令行）

1. 下载打包好的技能：<https://github.com/iamzifei/xiaobai-qa/releases/latest/download/xiaobai-qa.zip>
2. 打开豆包或 WorkBuddy 的技能管理页，点上传，选这个 zip
3. 新开一个对话，输入「新手指南」

### 用 Claude Code、Codex、Cursor

**一行命令装好**（需要电脑上有 Node.js）：

```bash
npx skills add iamzifei/xiaobai-qa -g
```

装完重开对话，输入 `/xiaobai-qa 新手指南`。

**不想敲命令**：技能要放进一个固定的文件夹（技能目录）。Claude Code 的技能目录是你个人文件夹下的 `.claude/skills`。

1. 下载 <https://github.com/iamzifei/xiaobai-qa/releases/latest/download/xiaobai-qa.zip>，双击解压，得到 `xiaobai-qa` 文件夹
2. 打开「访达」，按 `Shift + Command + G`，粘贴 `~/.claude/skills`，回车
3. 提示找不到的话，先粘贴 `~/.claude` 进去，在里面新建一个叫 `skills` 的文件夹
4. 把 `xiaobai-qa` 整个文件夹拖进去
5. 重开 Claude Code，输入 `/xiaobai-qa 新手指南`

### 博主回粉丝模式，装完多一步

在 `xiaobai-qa` 文件夹里找到 `config.example.yaml`，复制一份，改名成 `config.yaml`。用记事本或任何文字编辑器打开它，把引号里的内容换成你自己的。只改引号里面的字，冒号、缩进、引号都不要动：

| 要改的 | 说明 |
|---|---|
| `account` | 账号名、主要帮谁、回复里能用的自我介绍、不能提的身份 |
| `offers` | 免费入口（比如主页置顶视频）、付费入口（不填就永远不提） |
| `redlines.banned_words` | 回复里不许出现的词 |
| `paths` | 回复稿和粉丝聊天记录存在哪，写电脑上一个文件夹的完整路径 |

改完保存，重开对话就生效。**自己问模式不用改任何配置。**

### 聊天记录存在哪

- 自己问模式：聊完存在你个人文件夹下的 `小白答疑记录.md`，下次回来它会先看上次聊到哪
- 回粉丝模式：存在 `config.yaml` 里 `paths` 写的位置，每个粉丝一份，另有一份 `_总览.md` 列出谁还在等回复、哪类问题被问得多

## 三条规矩

1. **真问题没确认之前，不给建议。** 想帮你的冲动先忍住，换成一个更准的问题
2. **只给一步，不给清单。** 这一步用你已经有的东西，这周做得完，做完看得见结果
3. **不画饼。** 不承诺收益，不报别人赚了多少，不推荐要先交钱的项目。遇到「零基础、不用干活、一天能挣多少」一起出现的，它会提醒你捂紧钱包

如果你说的话里透出处境很难、撑不下去，它会先停下所有别的，告诉你可以打 **12356**（全国心理援助热线）。
